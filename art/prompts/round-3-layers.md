# Round 3: paper pieces for the real play screen

Purpose: the separate layers the game assembles and animates in code. Unlike rounds 1 and 2, these ship.

Generated on higgsfield.ai with GPT Image 2.6 Sunburst in Unlimited mode (no credits), 2K, PNG. Unlimited mode fixes the quality at Medium and runs one image at a time.

Status on 2026-11-19: prompts 1 to 5 are in use. Prompt 6 was generated but is not used, and prompt 7 was not run, because the banner, tray, keys, tags, pegs and thermometer are built in CSS (`src/paper/paper.css`) so they can stretch and hold live text. Each run attaches a round 2 image as the style reference, named under each heading. Originals go in `art/layers/originals/`, and `npm run art` cuts them into the pieces in `public/art/`.
